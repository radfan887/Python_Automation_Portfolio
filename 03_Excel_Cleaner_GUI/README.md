# 🖥️ Excel Cleaner GUI Application

Professional desktop application for cleaning Excel files with an intuitive graphical interface.

## ✨ Features

- 🎯 **User-Friendly Interface** - Easy to use for non-technical users
- 📊 **Real-time Processing Log** - See what's happening step by step
- 🔧 **Customizable Options** - Choose sort column and output folder
- 📈 **Detailed Statistics** - Get comprehensive cleaning reports
- 🚀 **Multi-threaded** - Interface doesn't freeze during processing

## 🔧 Installation

```bash
pip install pandas openpyxl
(Note: tkinter comes with Python by default)

🚀 How to Use
Run the application:

bash
python excel_cleaner_gui.py
Click "Browse" to select an Excel file

(Optional) Enter a column name to sort by

(Optional) Change output folder name

Click "Clean Excel File"

Watch the progress in real-time

Find cleaned file in the output folder
📋 Output Files
The application creates:

cleaned_filename.xlsx - The cleaned data

summary_filename.txt - Detailed cleaning report
