# 📊 Smart Excel Cleaner - Basic Version

A Python tool that automatically cleans and organizes messy Excel files.

## ✨ Features

- Remove empty rows and columns
- Remove duplicate entries
- Fill missing values with "N/A"
- Sort data by first column
- Generate summary report
- Save cleaned data in new file

## 🔧 Installation

```bash
pip install pandas openpyxl
🚀 Usage
bash
python main.py your_file.xlsx
Example:

bash
python main.py data.xlsx
📋 Output
The script creates a new file: cleaned_your_file.xlsx with two sheets:

Cleaned Data: The processed data

Summary: Statistics about the cleaning process
